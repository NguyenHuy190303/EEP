# Present

Use the existing kit, palettes and Vietnamese-capable fonts. For a diagram-only request use archify's renderer and delivery; do not add another authoring wrapper. Product UI belongs to impeccable. Preserve an explicitly chosen visual direction.

1. For a new visual artifact without a chosen style, follow [style selection](references/style-selection.md), including the existing gallery and the "None fits — Claude designs it" option. Reuse a style already chosen in this conversation.
2. Read only the selected style's README from [resource map](references/resource-map.md). Results showcase W3, report/explorable W1/W2 and video V1/V2 have different inputs; do not load all templates.
3. For authoring and delivery read [build and delivery](references/build-and-delivery.md). Keep atomic successful validation, screenshots in both supported themes, glyph/overflow checks and a real served preview. Never clip content or bypass a validator to claim success.
4. Only when modifying this skill's kit/templates read [maintenance](references/maintenance.md). An ordinary artifact does not require the maintenance suite.

`$K` means this skill's real base directory, not a shell variable remembered from a previous command. Preserve the server's existing private destination; do not publish elsewhere without authorization. An explanation that stays as plain chat/Markdown needs no visual style ceremony.
