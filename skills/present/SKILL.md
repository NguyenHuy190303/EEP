# Present

Use the existing kit, palettes and Vietnamese-capable fonts. For a diagram-only request use archify's renderer and delivery. Product UI belongs to impeccable. Preserve an explicitly chosen visual direction.

1. For a new visual artifact without a chosen style, follow [style selection](references/style-selection.md), including the existing gallery and the "None fits — Claude designs it" option. Reuse a style already chosen in this conversation.
2. Read only the selected style's README from [resource map](references/resource-map.md). Results showcase W3, report/explorable W1/W2 and video V1/V2 have different inputs; load only the selected one.
3. For authoring and delivery read [build and delivery](references/build-and-delivery.md). Done when validation passes on unclipped content, screenshots exist in both supported themes, glyph and overflow checks pass, and a real served preview loads. A validator failure is fixed in the content, never bypassed.
4. Only when modifying this skill's kit/templates read [maintenance](references/maintenance.md). An ordinary artifact does not require the maintenance suite.

`$K` means this skill's real base directory, not a shell variable remembered from a previous command. Deliver to the server's existing private destination; any other destination needs authorization. An explanation that stays as plain chat/Markdown needs no visual style ceremony.
