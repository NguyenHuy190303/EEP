# D2 — archify (default for architecture / stack design)

Lanes + arrows, rendered by the separate `archify` skill (not part of this plugin).

| File | Role |
|---|---|
| `kv-decode.workflow.json` | worked example: a workflow diagram with 3 lanes and 2 phases |

Write the JSON, then follow the `archify` skill to validate and render it. Size `meta.viewBox`
near the width `validate` reports as the floor. Past ~8 lanes or nodes, split into two diagrams.
To place the result inside a page, embed its SVG in a `<figure class="fig">`.
